## 💡 Sobre o projeto

Este é o meu portfólio online >> o lugar onde apresento quem eu sou, o que sei fazer e o que já construí até aqui.

A primeira versão foi desenvolvida com HTML, CSS e JavaScript puro, durante o curso de Front-End da Comunidade Dev Completo. Mas quando chegamos à introdução do React no final do curso, tomei uma decisão por conta própria: reescrever o site inteiro usando React.

Penei? Sim. Tive que pesquisar bastante, me virar com erros que não estavam no material, e entender na prática o que os exemplos tentavam explicar na teoria. Mas foi exatamente esse processo — de resolver por conta própria — que me fez realmente compreender o React. Não apenas seguir um tutorial, mas construir algo meu do zero com uma tecnologia nova.

O site é dividido em 5 seções: **Início**, **Sobre mim**, **Skills**, **Projetos** e **Contatos**. A seção de projetos também foi desenvolvida de forma independente, como um desafio proposto pela professora — e mais uma vez, fui atrás e resolvi sozinha (esse demorou hein... Fiquei dias tentando acertar! Hahaha).
